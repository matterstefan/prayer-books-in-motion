# Feedback and decisions

Consultation took place asynchronously through two email rounds to PRAYTICIPATE participants. The first invited missing-title suggestions and general feedback; the revised prototype was circulated again on 11 October, with feedback requested by 13 October. Stefan reported sending the first invitation to approximately 340 Action members. This is an invitation count, not a count of active collaborators. Private emails are not reproduced here.

| Input | Response in the prototype or decision |
|---|---|
| Salicetus Antidotarius and Petrarca penitential psalms | Added relevant GW entries to the core selection; MEI coverage determines displayed copies |
| Further liturgical material, including breviaries | Optional liturgical and devotional additions based on catalogue terminology |
| Links to visual material | Separate copy-level and edition-level digitisation links, with completeness caveat |
| Mapping Manuscript Migrations comparison | Informed exploration of the heatmap; no import of its data or country averages |
| Printing places without results in selected collections | Contextual counts, disabled zero-result options and clearer printing-place terminology |
| Different place-name languages | Existing preferred place identifications plus English filter labels; source labels retained |
| GW language export | Multilingual filtering and documented preferred source/fallback rules |
| Portuguese Horae in Washington | Already in core; stored MEI query had zero hits |
| Sacramental in Rio | Stefan’s manual check on 14 October found no MEI data; not added to the map |
| Jewish printing in Portugal | A Lisbon prayer commentary already appears with seven copies; broader printing history not automatically added |
| Ownership categories and regional filters | Retained as future development suggestions |
| Ottoman archival collaboration proposal | Potential later scholarly collaboration, outside this incunabula prototype |

The earlier 1518 Cologne suggestion was explicitly excluded by Stefan. Some exact identifications in the earlier feedback list remain deferred (see three-collections.md); the closure of this development round is not a claim that every bibliographical question has been resolved.

GW staff supported reuse and supplied an export. CERL contacts enabled authorised scripted retrieval. Neither institutional support nor feedback amounts to endorsement of every interpretation in the visualisation.
