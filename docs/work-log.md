# Project work log

This log documents the development of *Prayer Books in Motion*, including technical decisions, data-processing steps and consultation within the PRAYTICIPATE Action.

## 22 September 2026 — Initial project setup

**Project phase:** Preparatory work before the official VMG period  
**Time spent:** one working day

### Work completed

- Created the public GitHub repository `prayer-books-in-motion`.
- Added an initial README describing the project aims, corpus, data sources and methodological principles.
- Defined the project as an experimental reuse and visualisation of openly accessible data.
- Decided to document the technical workflow so that the project also serves as a practical introduction to GitHub and bibliographic data formats.

### Decisions

- No new catalogue or provenance data will be created.
- Source identifiers and catalogue terminology will be retained wherever possible.
- The initial corpus will combine the GW category *Horae* with selected prayer books recorded under their own work titles.
- Work undertaken before the official VMG period will be identified as preparatory work.

### Next steps

- Create the basic repository structure.
- Review the existing supplementary corpus table.
- Define the relationships between GW editions, ISTC records and MEI copies.
- Plan a documented consultation with members of the PRAYTICIPATE Action.
